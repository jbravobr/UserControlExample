# Controles reutilizáveis em Xamarin.Forms

> Exemplo de componente de interface reutilizável em uma aplicação Xamarin.Forms.

## Organização

- `Droid/` — projeto da plataforma Android.
- `ViewAsComponentExample/` — projeto ou módulo `ViewAsComponentExample`.
- `iOS/` — projeto da plataforma iOS.

Solução: [`ViewAsComponentExample.sln`](ViewAsComponentExample.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`ViewAsComponentExample.sln`](ViewAsComponentExample.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
